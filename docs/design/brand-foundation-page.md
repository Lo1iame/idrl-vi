## 展示约定

- 名称为「品牌基础 / Brand foundation」，路由 /#foundation，位于应用框架的「设计系统」分组；官网首屏操作区和页脚提供同一入口。
- 画廊按品牌理念、标志、颜色、字体、数字基础的原始顺序，使用 output/brand/foundation-1.png 至 foundation-5.png，不重绘原稿、不随界面主题反色。
- 缩略图可通过按钮放大。浮层有标题、页码、说明、前后页操作、Esc 关闭和关闭后焦点恢复；移动端保持比例；另有细节放大模式，在有名称、可键盘滚动的图像区域查看原稿文字，不使整页横向溢出。
- 完整 PDF 可新标签预览、下载；页面内阅读器按需打开，始终提供直接打开链接作为不支持内嵌 PDF 时的替代路径。
- 文案区支持中英文；原始图稿与 PDF 保留中文，不伪装为已翻译。
- 明确标识「视觉基础审核稿 v0.1 / 历史审核材料」，原稿中的日期、36 组色对及“下一阶段”等文字代表当时状态；当前 tokens、组件与接入能力以 DESIGN.md、组件页和 adoption.md 为准。
- 静态图片与 PDF 由构建器作为资产打包，不依赖开发服务器 /output 路径；默认 UI 接入快照不包含该展示页面及科研 / 审核二进制文件。
