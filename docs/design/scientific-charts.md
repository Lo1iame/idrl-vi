# IDRL 科研图表规范 v0.1

适用于论文插图、组会、公开报告与内部科研工具。品牌名称统一为「智能设计与鲁棒学习 / Intelligent Design and Robust Learning」。规范中的数值均为合成演示数据。

## 视觉语言

| 元素 | 默认规范 |
| --- | --- |
| 重点方法 | 品牌蓝 #236db9；实线、圆点 |
| 基线方法 | 深蓝 #203663；虚线、方点 |
| 辅助强调 | 青色 #56c0e5；不用作白底小字 |
| 文字 | #182a43；辅助文字 #52637a |
| 网格 | #dce4ef，细线，仅保留阅读数值所需的方向 |
| 背景 | 白色；无渐变、立体柱或阴影 |
| 字体 | 英文和数字 Inter；中文 Noto Sans CJK SC |

颜色始终搭配线型、点型或纹理编码，确保灰度打印仍能区分。多于三组时优先分面；如需新增类别色，应保持全篇映射一致并复核可辨性。不要把品牌色当作连续量色标；连续量选用单调明度色标，发散量明确中心值。

## 图形选择

| 研究问题 | 首选形式 | 关键要求 |
| --- | --- | --- |
| 多任务 / 多方法比较 | 分组柱图或点区间图 | 柱图数值轴从零开始；写明指标方向 |
| 训练与时间趋势 | 折线图 | 使用真实横坐标；默认不平滑 |
| 扰动 / 超参数敏感性 | 折线或散点图 | 给出强度定义、单位和评价协议 |
| 多次运行的不确定性 | 原始点 + 均值 / 区间 | 标注 n、独立单位和区间算法 |
| 消融与精确数值 | 表格 | 保留合理小数位；标注最好 / 次好规则 |
| 定性结果 | 对齐的图像面板 | 同尺度、同裁剪规则、同色标，包含失败样本 |

## 数据表达

1. 轴标签写「指标（单位）」；百分数明确是 0–1 还是 0–100。PPT 示例采用 0–100。
2. 对数轴标明底数；截断轴明确标注范围。跨图比较时固定范围，避免夸大差异。
3. 不确定性必须由实际重复数据计算；SD、SEM、置信区间不得混称。注明样本量和随机种子策略。
4. 仅在检验方法、比较对象和多重比较处理明确时标注显著性。无统计证据不使用星号。
5. 不跨缺失点连线；不把未观测值写成零。异常值处理与平滑算法须披露。
6. 在图注中记录数据版本、聚合方式、重复次数和代码版本。只突出数据支持的结论。

## 排版与导出

- 汇报：16:9，正文通常 18–24 pt，图表标注至少 14 pt；站在实际投影距离检查。
- 论文：以目标期刊版面尺寸为准，按最终尺寸检查字体；常用起点为 8–10 pt，不能直接把整张幻灯片缩小。
- 线宽在最终尺寸下约 1–1.5 pt，点径约 4–5 pt；图例紧邻证据，避免盖住数据。
- 优先导出 SVG / PDF 矢量版；同时提供 300 dpi PNG 兼容版。保留源数据、绘图脚本与字体授权。
- 交付前检查：单位、图例映射、数值精度、轴范围、灰度可辨性、误差定义、裁切和示例标记。

## 本仓库的可复用资产

- `output/research-template/idrl-research-template-v4.pptx`：16 页可编辑汇报模板，含 3 张原生图表、4 张原生表格。
- `output/research-template/illustrative-data.json`：PPT 图表的完整合成数据。
- `assets/brand/charts/idrl.mplstyle`：Matplotlib 样式。
- `scripts/build-scientific-charts.py`：导出比较柱图、学习曲线、鲁棒性曲线与重复运行误差图；输出到 `output/scientific-charts/`。
- 误差图采用独立的合成重复数据，展示均值 ± 样本标准差（n=5），不与 PPT 的单组展示值混用。

## 使用边界

PPTX 中的图表及数据工作簿可编辑；方法框图为可编辑形状与文字。公式页目前是文本公式示例，不是原生数学公式对象。Logo 使用原始资产导出的图片，保持比例。模板按页面复制使用，尚未制作自定义 PowerPoint 母版或 POTX。打开前安装仓库中的字体；跨软件打开后需复核换行与图表布局。


v4 使用深浅面板区分信息层次；任务差值及鲁棒性末端差值由同一份合成数据计算，不表示真实研究结论。
