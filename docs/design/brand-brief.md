# IDRL 品牌 VI 设计简报

## 已确认方向

- 中文名称：智能设计与鲁棒学习。
- 英文名称：Intelligent Design and Robust Learning。
- 缩写：IDRL。后续 logo 与 VI 名称文字不含 Laboratory。
- 主要受众：学术同行、潜在学生；兼顾企业合作伙伴。
- 品牌气质：严谨、探索为主，开放为辅。
- Logo 调整边界：保留核心图形识别，允许必要的几何规范化；重新整理中英文名称组合。
- 首批范围：基础 VI 规范、学术报告 PPT、学术海报、网站视觉规范、社交媒体模板，以及一套 UI 设计组件。
- UI 场景：团队官网、科研交互工具，以及团队内部自研应用。
- 平台：响应式 Web，覆盖桌面和手机浏览器。
- UI 交付：设计变量、组件及状态规范、示例页面、可运行组件库；主要服务于基于 agent 的 vibe coding，采用下文已确认的技术方向。
- 语言策略：提供中文、英文、双语三种 logo 组合；国内材料中文为主，国际学术材料英文为主。
- 配色：保留青蓝、中蓝、深蓝的关系，允许为屏幕显示、印刷及文字可读性微调；补齐中性色、功能色和深浅主题。
- 已确认交付格式：PPT 提供可编辑 PPTX，logo 提供 SVG、PDF、PNG，规范提供 PDF。
- Agent 使用方式：组件源码可复制，配套统一设计变量、agent 使用指南和示例页面。
- 应用组件范围：包含表格、筛选、表单、导航、弹窗、通知等完整应用组件；提供内容展示、数据工作台、设置表单三类示例。
- AI 交互范围：包含聊天、流式输出、工具调用、任务进度、审批确认等基础组件；模型接入按具体应用配置。
- 品牌表达：共享颜色、字体、间距体系；官网和宣传材料充分表达几何特征，内部工具优先内容清晰，在导航、重点操作、空状态中体现品牌。
- UI 可编辑资产：代码、设计变量和组件展示站为主。
- 海报交付：可编辑 PPTX 和印刷 PDF。
- DESIGN.md：作为 agent 应用 VI 与 UI 的主入口，说明品牌规则、组件选择、页面布局和交互要求，并关联设计变量、组件文档与示例；随各阶段成果持续更新。
- 技术栈：React、TypeScript、Tailwind CSS、shadcn 组件源码体系，配套 Storybook 和 IDRL 组件 registry。
- 应用框架：内部应用与科研工具默认使用 Vite；官网需要 SEO 或服务端渲染时使用 Next.js。共享组件不依赖 Next.js 专有能力。
- 字体方向：中英文日常文字采用清晰的无衬线字体，字体须可合法随项目分发；保留 logo 字标的几何特征，具体字体经字形与授权核对后确定。
- 科研组件：首版纳入图表、公式、代码展示、实验指标、日志查看；复杂流程画布、三维可视化、大型数据编辑器作为后续扩展。
- 可用性验收：键盘操作、清晰焦点、文字对比度、减少动态效果、加载／空白／错误状态；按 WCAG 2.2 AA 的适用要求验证，覆盖中英文与深浅主题。
- 实施节奏：先审核 logo 与视觉基础，再审核官网、数据工作台和 AI 交互示例，最后扩展完整组件、应用模板及规范。

## 设计阶段需验证

- 具体字体授权及中英文视觉协调。
- 标准 logo 的几何轮廓、组合比例及屏幕／印刷色值。
- 三类代表性示例的视觉效果与组件行为。
- DESIGN.md 与设计变量、组件示例的一致性。

用户于 2026-10-11 确认整体范围，第一阶段视觉基础审核稿已制作。

## 第一阶段成果

- 基于 AI 原始 Bézier 路径的图形、IDRL 字标与中英文名称组合：`assets/brand/logo/`。
- 字体提案：Inter 与 Noto Sans CJK SC，随资产保留字体及授权文件。
- 配色、字体、间距、圆角、动效及深浅主题语义变量：`assets/brand/tokens.json` 与生成的 CSS。
- Agent 设计入口：根目录 `DESIGN.md`。
- 五页视觉审核稿：`docs/design/foundation.html`，导出 PDF／PNG 位于 `output/brand/`。
- 36 组核心色对通过数值检查，报告：`docs/design/contrast-report.json`。不等同于完整组件无障碍验收。
- 2026-10-12 用户通过第一阶段视觉基础审核。

## 第二阶段成果

- 可运行的响应式官网概念、实验工作台、AI 交互，以及基础组件展示。
- 共享 React Button、Badge、Radix Dialog 与应用框架；Tailwind 主题映射和 token CSS。
- 工作台：搜索、状态筛选、空状态、新建演示记录、详情及 JSON 导出。
- AI：流式输出、停止、操作确认、模拟工具成功／失败、重试、Markdown 下载。
- 中英文切换、深浅主题与浏览器偏好保存。
- Web 预览字体为 WOFF2；中文按当前文案生成子集，原始字体和授权保留。
- 源码位于 src/，预览截图位于 output/ui/。所有页面为本地示例；无外部模型或业务服务接入。
- 审核后继续扩展完整组件库、registry、Storybook、PPT、海报、社交模板与最终规范。
