# 工作台布局与 UI 组件演进

本文保留访谈与分批实现范围；现行能力见 component-inventory.md，跨应用接入以 adoption.md 为准。

日期：2026-10-15。状态：两轮访谈已确认，第一批已实现，待视觉验收。用户第二轮回复“ok”，据此执行已提出的推荐范围。

## 已明确的目标

- 多个后续应用将采用与实验工作台类似的布局，需要逐步完善可复用的界面体系。
- 桌面端采用左侧侧边栏；侧边栏支持折叠；整体支持响应式布局。
- 增加更新日志页面。
- 丰富设计组件，继续遵循 IDRL 的 DESIGN.md 和品牌资产。

## 访谈前的实现

- `src/components/app-shell.tsx` 为实验工作台、研究助手、设计组件共用的布局，导航项和页面标题写在组件内部。
- 侧边栏没有折叠状态、折叠按钮或图标轨道；当前 CSS 在窄屏隐藏侧边栏，并显示移动端顶部导航。
- `src/App.tsx` 使用 hash 视图切换，现有页面为 website / workspace / assistant / components；没有更新日志路由。
- 组件页已有按钮、徽章、表单校验、弹窗、页签、密度切换与色值复制示例，尚非完整独立组件库。
- 本次访谈先定义后续应用的共同约定，再决定实现批次。官网展示动效不自动扩展到高密度工作台。

## 第一轮已确认决策

用户于 2026-10-15 回复“按推荐”，以下四项确认。

| 决策 | 讨论事项 | 已确认方案 |
| --- | --- | --- |
| 复用范围 | 页面示例、可配置框架，或独立发布的组件包 | 可配置应用框架 + 基础 UI 源码 + 页面模板；暂不独立发布 npm 包 |
| 导航形态 | 折叠后保留什么；手机与平板如何处理 | 桌面展开 / 图标轨道切换，平板默认轨道，手机使用抽屉 |
| 日志对象 | 记录 VI / 组件版本，还是业务应用动态 | 当前仓库先展示设计系统更新；下游使用同一模板记录自己的产品更新 |
| 组件优先级 | 优先支持哪些真实应用工作流 | 导航与布局 → 数据表格 / 筛选 / 表单 → 反馈 / 浮层与复合组件 |

- 图标轨道保留当前项高亮，并为鼠标悬停和键盘焦点提供名称提示。
- 手机抽屉支持遮罩、Esc 关闭和焦点恢复；桌面折叠偏好按应用记忆，不与手机抽屉状态混用。
- 更新日志按版本、日期以及新增 / 改进 / 修复分类；下游复用模板，各自维护日志。

## 第二轮已确认决策

| 问题 | 已确认方案 |
| --- | --- |
| 导航配置范围 | 应用标识、名称、logo、分组导航、当前项、面包屑、顶部操作可配置；首批支持分组单层导航，不引入无限嵌套树 |
| 日志维护方式 | 仓库内类型化本地数据，由 Git 维护版本 / 日期 / 分类 / 条目；先无 CMS 或后台，历史记录基于真实提交 |
| 首批实现与验收 | 应用框架 + 日志页面 + Tooltip / 抽屉 / 面包屑等所需组件；补充组件页示例，之后再进入表格和表单增强 |

建议验收：桌面 ≥1024px 默认展开，768–1023px 默认图标轨道，手机 <768px 抽屉；跨断点不改变桌面偏好；手机选中导航后关闭抽屉。当前 hash 导航保留，框架本身不绑定具体路由库。深浅主题、中英切换、键盘操作、存储不可用时的降级均需验证。

## 第一批实现与验证

- `AppShellConfig` 定义应用身份、分组单层导航及品牌节点；布局额外支持面包屑与顶部操作。
- 桌面偏好按 `idrl-sidebar:<appId>:collapsed` 保存；平板临时展开和手机抽屉均不改写桌面偏好。
- Tooltip 提供悬停 / 键盘名称提示；Sheet 基于 Radix Dialog 提供遮罩、焦点约束、Esc、关闭后焦点恢复。
- 更新日志为独立 `#changelog` 页面，首批整理 2026-10-12、13、14 的真实提交；未提交的新功能不伪装为已发布版本。
- 组件页增加导航框架区、Tooltip / Sheet / Breadcrumb 实际演示及调用示例。
- 8 项框架测试涵盖跨页 / 刷新 / 断点、独立应用偏好、存储降级、抽屉遮罩 / Esc / 焦点 / 路由 / 缩放、双语与日志主题布局。原有 19 项回归也通过。
- 详细接入步骤见 `docs/design/app-shell-integration.md`。组件库仍是源码复用，不是完整独立包；多级导航、表格增强、registry、Storybook 留待后续批次。

CONTEXT.md 已补充 IDRL 应用框架与设计系统更新日志术语；本轮未引入数据库、路由框架或组件发布平台等需要单独 ADR 的长期依赖。

## 第二批：本地数据表格

- 提取通用 DataTable 和 DataColumn，接入实验记录，保留详情、筛选、新建、导出。
- 组件页提供 7 条独立、明确标注的演示记录，展示分页、每页数量、排序和空状态。
- 缺失得分始终置后；搜索、筛选和新增记录返回第一页。工作台导出完整筛选集合。
- 先采用已安装 React 和原生语义 table，无新增依赖；服务端数据、批量选择、虚拟化及高级表单留待后续批次。
- 复用接口和边界见 DESIGN.md「数据表格」。

## 第三批：共享表单

- 新增 FormField、Textarea、Checkbox、Switch，标签 / 帮助 / 错误统一关联，选择控件支持键盘与禁用状态。
- 组件页迁移表单，并展示多行说明、字符上限、摘要选项的实际变化及重置。工作台新建弹窗共用字段，同时保留原生数值校验。
- 保持本地示例边界；复杂校验库、服务端字段错误、异步提交与上传控件后续按真实应用需要扩展。
